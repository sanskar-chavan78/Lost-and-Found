Lost & Found Portal - Client Delivery Package

REQUIREMENTS:

* Windows Operating System
* Node.js LTS (Long Term Support) installed once
* Active internet connection (to connect to MongoDB Atlas database)

INSTALLATION:

1. Extract the ZIP package fully to a folder.
2. Download and install Node.js LTS (from https://nodejs.org/).
3. Double-click INSTALL.bat inside this folder.
4. Wait until the automated setup and dependencies installation finishes.

START:

1. Double-click START.bat.
2. Wait a few seconds for database verification.
3. The browser will open automatically to http://localhost:3000.
4. Keep the console window open to view live logs.

STOP:

1. Double-click STOP.bat (or press Ctrl+C in the active runner window).

TROUBLESHOOTING:

* Double-click CHECK.bat to run full system diagnostics.
* Read the check result and error details (PASS, WARNING, ERROR).
* Resolve any network connectivity or credential issues as reported.
* Contact the developer if assistance is required.
